Before We Start: Understanding the R Console

The R console is where we interact with R. When you see a > symbol, that’s your prompt to enter commands. In the interactive code blocks below, you’ll be able to type and run R code directly.

Pro Tip

Don’t worry about making mistakes! Experimentation is a key part of learning. If you get an error, read the message carefully - R usually tells you what went wrong.

2. Variables and Assignment

Variables are like containers that store values. In R, we typically use the <- operator for assignment:

Naming Rules
  • Variable names can contain letters, numbers, dots (.) and underscores (_)
  • They must start with a letter or a dot
  • R is case-sensitive: Fish and fish are different variables
  • Use descriptive names: total_catch is better than tc

4. Vectors: Collections of Values

Vectors are one-dimensional arrays that can hold multiple values of the same type:

Working with Vectors
  • Use c() to combine values into a vector
  • All elements in a vector must be of the same type
  • If you mix types, R will convert them to the most flexible type
