Introduction 🎯

Welcome to your guide to basic R operations! This tutorial will take you through the fundamental operations in R, building from simple calculations to more complex operations. We’ll learn by doing, with plenty of examples and explanations.

Learning Objectives

By the end of this tutorial, you will be able to: - Perform basic calculations in R - Understand different data types - Create and manipulate variables - Work with vectors and basic data structures - Use basic R functions - Understand logical operations

Order of Operations

R follows the standard mathematical order of operations (PEMDAS): 1. Parentheses 2. Exponents 3. Multiplication and Division (left to right) 4. Addition and Subtraction (left to right)

2. Variables: Storing Values 📦

Variables are containers for storing values. In R, we create variables using the assignment operator <- (or =, but <- is more common in R).

Creating Variables

Variable Naming Rules
  1. Names can contain letters, numbers, dots (.) and underscores (_)
  2. Names must start with a letter or a dot
  3. Names cannot start with a number
  4. Names are case-sensitive (Fish ≠ fish)
  5. Avoid using R’s reserved words (like if, for, function)

Practice Exercises 💪

Let’s consolidate what we’ve learned with some exercises:

Exercise 1: Basic Calculations

Try to calculate: 1. The area of a circle with radius 5 (use pi for π) 2. The volume of a sphere with the same radius 3. Round both results to 2 decimal places

Exercise 2: Working with Vectors

Create a vector of fish weights (in kg): 1.2, 2.3, 3.4, 2.1, 1.9 1. Calculate the total weight 2. Find the average weight 3. Identify weights above 2 kg 4. Count how many fish weigh more than 2 kg

Exercise 3: Combining Operations

You have caught fish of different species. Create vectors for: 1. Species names: “Tuna”, “Mackerel”, “Sardine”, “Tuna”, “Mackerel” 2. Weights: 2.5, 1.2, 0.5, 2.3, 1.1 3. Calculate the average weight per species

Practice Makes Perfect! 🎯

The best way to learn R is by practicing. Try to: 1. Modify the examples provided 2. Create your own variables and vectors 3. Experiment with different functions 4. Work through the exercises multiple times 5. Create your own exercises based on real data

Remember: Don’t worry about making mistakes - they’re a natural part of learning!

Tips for Learning
  • Type out the code yourself instead of copying and pasting
  • Try to predict what code will do before running it
  • If you get an error, read it carefully - R usually tells you what’s wrong
  • Keep notes of new functions and operations you learn

Need help? Remember you can: 1. Check the R documentation with ?function_name 2. Practice with the interactive exercises above
