Introduction 🎯

Data frames are R’s way of storing tabular data - think of them like spreadsheets. They’re the most common way to work with fisheries data, and understanding them is crucial before we dive into more advanced data manipulation.

Learning Objectives

By the end of this tutorial, you will: - Understand what data frames are - Know how to create and inspect data frames - Be able to access and modify data frame contents - Understand basic data frame operations

What is a Data Frame? 📊

A data frame is a 2-dimensional table where: - Each column can hold different types of data (numbers, text, etc.) - All columns must have the same length - Each column has a name

Think of it like an Excel spreadsheet: - Rows are observations (e.g., individual fish) - Columns are variables (e.g., species, length, weight)

Common Mistakes to Avoid ⚠️

Watch Out For:
  1. Mixing data types in columns
  2. Forgetting to handle missing values (NA)
  3. Using the wrong type of brackets [ vs [[ vs $
  4. Not checking data frame dimensions before operations
